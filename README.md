# 🚀 Proiect Final - Testare Automatizată UI (hapifyMe)

## 📝 Descriere Proiect
Acest proiect reprezintă suita finală de teste automatizate pentru platforma [hapifyMe](https://test.hapifyme.com). Framework-ul se concentrează pe testarea fluxurilor end-to-end din cadrul platformei (cum ar fi modulele de Login și Register), asigurând calitatea și stabilitatea aplicației înainte de deployment.

---

## 🛠️ Tehnologii Utilizate
* **Limbaj de programare:** Java
* **Framework de Testare:** TestNG
* **UI Automation:** Selenium WebDriver (rulat în mod Headless pentru CI)
* **Build Tool:** Maven
* **CI/CD Pipeline:** GitHub Actions

---

## 💻 Instrucțiuni de Rulare Locală

Pentru a rula întreaga suită de teste direct pe calculatorul tău, deschide un terminal în rădăcina proiectului și execută comanda:

```bash
mvn test
